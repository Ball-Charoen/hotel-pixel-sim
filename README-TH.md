# วิธีย้ายโปรเจกต์ไปทำต่อใน Claude Code

## สิ่งที่อยู่ในโฟลเดอร์นี้
- `CLAUDE.md` คำสั่งประจำโปรเจกต์ Claude Code อ่านไฟล์นี้ทุกครั้งที่เริ่มงาน
- `FIRST-PROMPT-TH.md` ข้อความสำหรับวางในการคุยครั้งแรก
- `docs/` สรุปการออกแบบ แหล่งอ้างอิง และไฟล์ Excel สรุป v0.2
- `prototype/` เกมต้นแบบ P0 v0.3 (เปิดเล่นในเบราว์เซอร์ได้เลย)
- `src/sim/core.js` ระบบจำลองเศรษฐกิจของเกม พร้อมชุดทดสอบใน `tests/`
- `assets/art-templates/` เทมเพลตงานภาพ ส่วนภาพที่วาดเสร็จให้วางใน `assets/sprites/`

## ขั้นตอน
1. แตกไฟล์ zip แล้ววางโฟลเดอร์ `hotel-pixel-sim` ไว้ในที่ที่หาง่าย เช่น Documents
2. ติดตั้งแอป Claude Desktop จาก https://claude.ai/download แล้วเข้าสู่ระบบ เปิดแท็บ **Code** (ต้องใช้แผน Pro, Max, Team หรือ Enterprise)
3. เลือก Project folder เป็นโฟลเดอร์ `hotel-pixel-sim`
4. เลือกโหมดสิทธิ์ **Ask permissions** เพื่อให้ Claude ถามก่อนแก้ไฟล์หรือรันคำสั่งทุกครั้ง
5. คัดลอกข้อความทั้งหมดใน `FIRST-PROMPT-TH.md` ไปวางแล้วกด Enter
6. ถ้า Claude ขอติดตั้ง Node.js หรือแพ็กเกจ ให้อ่านคำอธิบายก่อน แล้วค่อยกดอนุญาต
7. ดูเกมระหว่างพัฒนาผ่านปุ่ม Preview ในแอป
8. ตรวจว่า Claude อ่านคำสั่งประจำโปรเจกต์แล้ว: พิมพ์ `/context` แล้วดูว่ามี CLAUDE.md อยู่ในรายการ

## ไม่บังคับ แต่แนะนำ
- ✅ เอกสาร System Design ฉบับเต็มส่งออกแล้ว อยู่ที่ `docs/system-design-v0.3.md`
- ให้ Claude ตั้ง Git ให้ตั้งแต่วันแรก จะย้อนกลับเวอร์ชันได้ถ้าแก้พลาด
- สำรองโฟลเดอร์นี้ไว้ที่ Google Drive เป็นระยะ
